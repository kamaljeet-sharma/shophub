# ShopHub 🛒

A full-stack MERN E-commerce web application where users can browse products, add items to cart, place orders, and manage their shopping experience online.

---

## 🚀 Features

* User Authentication & Authorization
* Product Listings
* Add to Cart Functionality
* Secure Checkout
* Order Management
* Responsive UI Design
* Admin Product Management
* MongoDB Database Integration
* REST API Integration

---

## 🛠️ Tech Stack

### Frontend

* React.js
* CSS
* Bootstrap / Tailwind CSS

### Backend

* Node.js
* Express.js

### Database

* MongoDB

### Other Tools

* Git & GitHub
* JWT Authentication
* Axios

## ⚙️ Installation

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/kamaljeet-sharma/shophub.git
```

### 2️⃣ Navigate to Project Folder

```bash
cd shophub
```

### 3️⃣ Install Dependencies

```bash
npm install
```

### 4️⃣ Create `.env` File

```env
MONGO_URI=your_mongodb_connection
SECRET=your_secret_key
PORT=8080
```

### 5️⃣ Start the Server

```bash
npm start
```
